The web UI for https://github.com/rhusiev/newsense

## Install as an app

Newsense is an installable web app. It still needs a connection to read news in this version.

- **Android Chrome:** open https://news.r1a.nl/, tap the three-dot menu, then **Install app** or **Add to Home screen**
- **iOS Safari:** open https://news.r1a.nl/, tap **Share**, then **Add to Home Screen**. The installed app has its own storage on iOS, so you may need to sign in again
- **Desktop Chromium:** use the install icon in the address bar

The installed app opens in its own window. Sign-in, feeds, and articles work as they do in the browser. If the connection drops, Newsense shows an offline page instead of a stale or signed-in copy.
